# 🏨 HostelHub – Hostel Room Allocation DApp

## 📌 About
HostelHub is a blockchain-based DApp for managing hostel room availability, booking, and allocation using Solidity smart contracts.

## ✨ Features
- Check room availability
- Book available rooms
- Manage room allocation
- Admin-controlled room management
- Store allocation records on blockchain

## 🛠️ Technologies
- Solidity
- Remix IDE
- Ganache
- HTML, CSS, JavaScript
- ethers.js

## 📂 Project Structure
- `HostelRoomAllocation.sol` – Smart contract
- `index.html` – Webpage structure
- `style.css` – Website styling
- `app.js` – Blockchain connection
- `screenshots/` – Project screenshots

## ⚙️ How to Run
1. Start Ganache.
2. Compile and deploy the contract using Remix IDE.
3. Configure the contract address and RPC URL in `app.js`.
4. Open `index.html` using VS Code Live Server.

## ✅ Advantages
- Transparent allocation records
- Reduced manual work
- Easy room availability checking
- Smart contract-based validation

## 🔮 Future Scope
- Student registration
